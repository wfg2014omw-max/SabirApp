# 🎭 Facebook Auto Creator

## 📌 وصف المشروع
أداة آلية لإنشاء حسابات فيسبوك باستخدام Selenium و undetected-chromedriver.

## ⚠️ تنبيه
**هذا المشروع للأغراض التعليمية فقط. استخدامه قد يخالف شروط خدمة فيسبوك.**

## 🚀 المميزات
- إنشاء حسابات تلقائياً
- دعم البروكسيات
- حل الكابتشا (يدوياً أو عبر 2Captcha)
- واجهة سطر أوامر غنية
- حفظ الحسابات في ملف JSON
